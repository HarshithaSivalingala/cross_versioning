ID       : pytorch_01_remove_variable
Framework: pytorch
Category : autograd
====================================================================================================

INPUT (PyTorch legacy)
-----------
```python
import torch

inputs = torch.autograd.Variable(torch.ones(4, 3), requires_grad=True)
weights = torch.autograd.Variable(torch.ones(3, 2))
outputs = torch.mm(inputs, weights)
print(outputs.data)
```

EXPECTED (PyTorch modern)
--------------
```python
import torch

inputs = torch.ones(4, 3, requires_grad=True)
weights = torch.ones(3, 2)
outputs = torch.mm(inputs, weights)
print(outputs.detach())
```

----------


====================================================================================================
ID       : pytorch_03_loss_item
Framework: pytorch
Category : training_loop
====================================================================================================

INPUT (PyTorch legacy)
-----------
```python
import torch

x = torch.autograd.Variable(torch.randn(10, 5))
w = torch.autograd.Variable(torch.randn(5, 1), requires_grad=True)
y = torch.matmul(x, w)
loss = y.sum()
loss.backward()
print(loss.data[0])
```

EXPECTED (PyTorch modern)
--------------
```python
import torch

x = torch.randn(10, 5)
w = torch.randn(5, 1, requires_grad=True)
y = torch.matmul(x, w)
loss = y.sum()
loss.backward()
print(loss.item())
```

LLM OUTPUT
----------
